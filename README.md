# 🎨 Simple Drawing App

A minimalist drawing application built with HTML, CSS, and JavaScript. Draw freely on a canvas with a clean and simple interface.

## 🚀 Features

- **Free drawing** - Click and drag to draw on the canvas
- **Crosshair cursor** - Precise cursor for accurate drawing
- **Clean interface** - Minimalist design with focus on drawing area
- **Responsive canvas** - Fixed 800x600 drawing area with subtle border

## 💡 How to Use

1. Open the application in your browser
2. Click and hold the left mouse button on the canvas
3. Move your mouse to draw
4. Release the mouse button to stop drawing

## 🎯 Drawing Controls

- **Draw**: Click + drag mouse
- **Line width**: Fixed at 5px (coming soon: adjustable)
- **Color**: Black (coming soon: color picker)
